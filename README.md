## 🚀 Technical Overview

This project serves as a practical implementation of modern web extension technologies, featuring:

- **Manifest V3 / Extension Architecture:** Background scripts, content scripts, and page-level interactions.
- **Real-Time Data Parsing:** Inspecting and responding to dynamically rendered game state UI components.
- **Custom UI Injection:** Overlaying user interface elements directly into the browser viewport.
